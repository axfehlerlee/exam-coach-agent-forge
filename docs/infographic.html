AI Exam Coach

손해사정사 문제 생성 + Slack 퀴즈 배포
— 어떻게 돌아가나요?

주제만 넣으면 AI가 새 문제를 만들고, 슬랙으로 퀴즈를 내고, 바로 채점·해설까지 해주는 흐름이에요. 아래를 따라 내려오면 한눈에 보여요.

한눈에 보기 · 4단계

📚출제범위
→
✍️문제 생성
→
💬Slack 퀴즈
→
📈학습 분석
1

📚 출제범위 정하기

data/exam-syllabus.json

실제 기출문제 원문은 올리지 않아요. 주제·단원만 참고해서 "같은 주제의 새 문제"를 만드는 게 핵심이에요.

  • 1차(객관식) 3과목 — 보험업법 · 보험계약법(상법 보험편) · 손해사정이론
  • 2차(서술형) 4과목 — 종류별(재물/차량/신체/종합), 지금은 자리만 잡아둔 상태라 정은님이 수정해요
▼
2

✍️ 문제 생성기

src/question-generator.mjs

주제를 넣으면 AI가 같은 주제로 새 문제를 써줘요.

  • 두뇌(AI) 선택 — ① Qwen 무료 등급(키가 있을 때) ② 키가 없으면 오프라인 템플릿 추가 비용 0원
  • 만들어 주는 것 — 문제 + 보기(A/B/C/D) + 정답 + 해설 + 오답코드(약점 표시용)
▼
3

💬 Slack 봇 — 배포 & 채점

src/slack/app.mjs · Socket Mode

만든 문제를 슬랙 채널로 내보내고, 버튼 하나로 바로 채점해요.

  • 관리자 — 슬랙에서 /퀴즈배포 <과목> <문항수> 입력 → 채널에 퀴즈가 게시돼요
  • 학습자 — 보기 버튼 클릭 → 즉시 "정답 여부 + 해설" 피드백, 틀리면 오답코드로 약점 표시
  • 원하면 매일 자동 배포도 설정할 수 있어요 (선택)
▼
4

📈 학습 분석

src/core.mjs

여기는 기존 제품 로직이에요. 퀴즈 결과가 자동으로 이어져요.

  • 오답코드 → 복습 우선순위 → 학습 개입 효과 측정으로 연결
🔒

개인정보는 레포에 올리지 않아요

개인정보 · 실제 학습자 데이터 · 토큰(비밀키)은 코드 저장소(레포)에 올리지 않습니다. 토큰은 정은님의 로컬 .env 파일에만 저장돼요.

✅ 정은님이 직접 하실 일 (3가지)

이 세 가지만 하면 퀴즈 배포를 시작할 수 있어요.

  1. data/exam-syllabus.json에서 2차 출제범위를 실제 범위로 수정하기
  2. Slack App 만들고 봇 토큰 발급 → 로컬 .env에 입력문서 docs/slack-setup.md 참고
  3. npm run slack 실행하면 퀴즈 배포 시작!
